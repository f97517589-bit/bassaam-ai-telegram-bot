# Bassaam AI Telegram Bot

بوت تلجرام للمحادثة مع نموذج ذكاء اصطناعي عبر Groq API.

## المزايا الحالية
- محادثة نصية مع الذكاء الاصطناعي.
- حفظ سياق منفصل لكل مستخدم باستخدام SQLite.
- الأمر `/new` لمسح سياق المستخدم.
- الأمر `/stats` للمشرف.
- إعدادات الأسرار عبر متغيرات البيئة، وليس داخل الكود.

## متغيرات البيئة المطلوبة
- `TELEGRAM_BOT_TOKEN`: رمز البوت من BotFather.
- `GROQ_API_KEY`: مفتاح Groq API.
- `GROQ_MODEL`: اسم النموذج، الافتراضي `openai/gpt-oss-20b`.
- `ADMIN_IDS`: رقم حساب تلجرام للمشرف، ويمكن وضع أكثر من رقم مفصول بفواصل.
- `DATABASE_PATH`: مسار قاعدة البيانات، الافتراضي `bot_data.sqlite3`.

## تشغيل محلي
```bash
pip install -r requirements.txt
python main.py
```

## تنبيه الاستضافة
قاعدة SQLite مناسبة للاختبار أو للاستضافة ذات القرص الدائم. إذا كانت منصة الاستضافة تمسح الملفات عند إعادة التشغيل، استخدم قرصاً دائماً أو ننقل قاعدة البيانات إلى PostgreSQL في مرحلة النشر.

لا ترفع مفاتيح API أو توكن البوت إلى GitHub. أضفها في إعدادات Environment Variables في منصة الاستضافة.
